# 构图模式

## 结构类型

每张图只选一个：

| 类型 | 适用场景 |
|------|----------|
| 前后对比 | 过去 vs 现在、两种逻辑、两种关系 |
| 概念隐喻 | 抽象判断需要物理化（脊骨、漏斗、镜子） |
| 角色状态 | 人物处在某种张力或悖论中 |
| Workflow | 信息/信号/流程的传递与变形 |
| 系统局部 | 三角关系、双主体、分层结构 |
| 方法分层 | 多个对齐、多个原则并列但有关联 |
| 地图路线 | 导航型文章、阶段路径 |
| 小漫画分镜 | 2-3 格轻量叙事 |

## 隐喻发明原则

1. 从文章里找一个**动作**或**物件**，不要找抽象词
2. 低科技、怪诞但成立：凳子、绳子、镜子、层级墙、虚线轮廓
3. YoYo 必须正在做这个动作，不是旁观
4. 不要复刻 Ian 小黑案例或本 skill 已有例图的构图

## YoYo 常见动作

- 拉线汇聚信息
- 站在当下与未来之间的边界上挖地基
- 量一个还不存在的虚线轮廓
- 在三角关系里承担第三个角
- 被诱惑气泡包围但只往一个方向走
- 传递/接收两种不同性质的「光」或「信号」

# YoYo IP

## 角色定义

**YoYo** 是 TeacherYo 公众号正文配图的固定视觉 IP。

不是真人照片贴图，而是参考本人形象提炼出的手绘简笔角色——在怪诞正文配图风格里，承担核心动作的主体。

## 外形（生成时必须遵守）

- **发型**：齐肩偏短的红棕色头发，有短刘海
- **裙装**：明黄色无袖宽松连衣裙，下摆到**膝盖**即止
  - 不要及踝、不要拖地、不要配裤子
  - 轻盈、不拖沓
- **体型**：修长、轻盈，动作舒展，有「正在做事」的动感
- **画法**：黑色细线手绘轮廓 + 少量平涂填色（以黄色裙装为主）
- **表情**：自然、有神、带一点轻快笑意；不要呆板、不要空脸、不要小黑那种 deadpan 表情
- **比例**：略简化的人体比例，像白板上的产品草图人物，不是 Q 版

## 性格与动作

- YoYo 必须参与画面的核心动作，不能只是站在角落当装饰
- 像一个正在认真处理某个荒诞但成立隐喻的「工作者」
- 怪诞、清爽、有创意，但不幼稚

## 禁止

- 不要把真人照片直接贴进画面
- 不要画成写真、3D、精致商业插画
- 不要过度可爱、儿童卡通
- 不要让黄色裙装消失
- 不要让裙子长度漂移（必须膝盖长度）
- 不要让 YoYo 只当旁观者

## 判断标准

去掉 YoYo，图的核心隐喻还能完全成立 → YoYo 太装饰了，要重写提示词。
